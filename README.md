# NOPLUZ 官网

纯 HTML、CSS、JavaScript 的响应式物联网官网，无构建步骤、第三方依赖或外部字体请求。

## 运行

直接打开 `index.html`，或从仓库目录运行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

## 内容与交互

- 智慧工业、智慧园区、智慧能源场景展示。
- 三种平台能力选项卡，支持左右方向键、Home、End。
- 移动端导航与本地咨询内容生成、复制。
- 平台数字明确标注为示例数据。

这是官网设计原型。发布前需核实品牌名称、公司介绍、业务能力、正式联系方式及适用的备案信息。咨询表单不会发送消息，也不存储个人信息；实际收件功能需要另行接入后端服务。
